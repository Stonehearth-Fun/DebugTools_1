# Debug Tools 1.0

`Debug Tools 1.0` — мод для отладки и разработки контента для **Stonehearth**.
Он добавляет набор экранных инструментов, команд консоли и серверных вызовов,
которые позволяют исследовать состояние игры, создавать и изменять сущности,
проверять AI, кампании и производительность без правки сохранения вручную.

Внутренний идентификатор мода: `debugtools_1_0`.

> Мод имеет статус `is_debug_mod` и по умолчанию выключен. Он рассчитан на
> разработку, тестирование и диагностику, а не на обычное прохождение игры.

## Возможности

### Инспектирование и диагностика

- **Object Browser** — просмотр объектов и их данных, включая необработанные
  данные и приватные переменные; переход по истории, выбор и отслеживание
  сущности, загрузка списка всех сущностей.
- **Entity Inspector** — просмотр дерева AI и текущего поведения выбранной
  сущности.
- **Job Monitor** — мониторинг задач и профессий.
- **Trace Monitor** — просмотр отладочных трассировок.
- **Campaign Browser** — просмотр состояния кампаний, квестов и этапов игрового
  мастера.
- **Performance Monitor** — включение и выключение профилирования долгих тиков.
- **Session Logger** — журналирование команд и событий сессии в каталог логов
  мода, если игра разрешает в него запись.

### Работа с сущностями и миром

- создание сущностей и размещение предметов в мире;
- редактирование параметров выбранной сущности: `mob`, `destination`, коллизий,
  регионов, точек смещения и поворота;
- создание граждан, выдача опыта, повышение профессии, изменение атрибутов,
  здоровья, ресурсов, настроения, черт, мыслей и баффов;
- добавление золота, заполнение или очистка хранилищ, обновление и уничтожение
  объектов, ускорение роста и обновление возобновляемых ресурсов;
- перемещение и поворот сущностей, принудительный пересчёт компонентов и AI;
- запуск сценариев и встреч игрового мастера, управление предметами разговоров
  и отображение анимационного текста.

### Консоль и Lua

- расширенные команды отладочной консоли для типовых операций с выделенной
  сущностью и поселением;
- **Lua Console** для выполнения Lua-кода на сервере или клиенте;
- выделенная сущность в Lua Console доступна через глобальную переменную `e`;
- горячая клавиша по умолчанию: <kbd>`</kbd> (обратная кавычка) — открыть Lua
  Console.

## Как использовать

1. Установите папку `debugtools_1_0` как мод Stonehearth.
2. Включите **Debug Tools 1.0** в списке модов: по умолчанию он отключён.
3. Загрузите тестовую игру и откройте нужный инструмент с отладочной панели
   либо используйте отладочную консоль.
4. Для Lua Console нажмите <kbd>`</kbd>; выберите режим **Server** или
   **Client** перед выполнением кода.

## Структура проекта

- `manifest.json` — объявление мода, UI-ресурсов, команд и hotkeys.
- `debugtools_1_0_server.lua` — запуск серверных сервисов.
- `call_handlers/` — серверные и клиентские обработчики команд.
- `services/server/` — трекер сущностей и журнал сессии.
- `ui/` — окна интерфейса и команды консоли (`HTML`, `JavaScript`, `LESS`).
- `data/hotkeys.json` — назначение горячих клавиш.
- `mixintos/` — расширение действия прерывания AI.

## Важные ограничения

- Команды могут менять мир, сущности, AI и игровые ресурсы; перед тестами
  сделайте копию сохранения.
- Lua Console исполняет переданный код без дополнительной защиты. Используйте
  только код, которому доверяете.
- Мод использует API и структуру отладки Stonehearth, поэтому совместимость
  зависит от версии игры и других модов.

## Разработка

Проект не содержит отдельной сборки: интерфейсные исходники хранятся напрямую
в `ui/`. При добавлении функции нужно зарегистрировать её в `manifest.json` и,
если она доступна из UI, использовать namespace `debugtools_1_0` во всех
вызовах, локализации и hotkeys.
